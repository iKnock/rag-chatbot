PDF Processing and Storage Flow

sequenceDiagram participant C as Client participant S as Server.js participant PC as PDF Controller participant PP as PDF Parser participant VS as Vector Store participant CDB as Chroma DB C->>S: POST /process-pdf S->>PC: Forward PDF PC->>PP: Parse PDF PP-->>PC: Return Parsed Text Note over PC,PP: Text includes:
1. Extracted content
2. Metadata
3. Structure info PC->>VS: Create Vectors from Text Note over PC,VS: Vector creation:
1. Text chunking
2. Vector embedding
3. Metadata attachment VS->>CDB: Store Vectors & Metadata CDB-->>VS: Confirm Storage VS-->>PC: Storage Complete PC-->>S: Process Complete S-->>C: Success Response

Chat Flow with Vector Store Integration

sequenceDiagram participant C as Client participant S as Server.js participant PC as PDF Controller participant VS as Vector Store participant CDB as Chroma DB participant OS as Ollama Service participant OL as Ollama API C->>S: POST /chat (query) S->>PC: Forward Query PC->>VS: Search Similar Content VS->>CDB: Query Vectors Note over VS,CDB: Search params:
1. Query embedding
2. Similarity threshold
3. Top k results CDB-->>VS: Return Relevant Vectors VS-->>PC: Return Matched Content Note over VS,PC: Content includes:
1. Similar passages
2. Relevance scores
3. Source metadata PC->>OS: Generate Response Note over PC,OS: Context building:
1. Query
2. Retrieved content
3. Chat history OS->>OL: Enhanced LLM Request OL-->>OS: Generated Response OS-->>PC: Formatted Response PC-->>S: Final Response S-->>C: Send to Client
